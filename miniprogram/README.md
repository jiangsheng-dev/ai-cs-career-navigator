# 证书竞赛工作台 · 微信小程序

配合仓库根目录的 `index.html` 使用的手机端小程序：选证书/竞赛、看倒计时、记待办、写入手机日历提醒。

## 功能

- **记事本**：首页自己添加待办，点圆圈勾选完成后自动消失（保存在本机）
- **倒计时**：把想考的证书/比赛加入目标，自动算出下一个节点还有多少天
- **选择**：搜索 + 按比赛/证书筛选，数据来自工作台快照（30 项）
- **详情**：主办单位、合适专业、初复赛、作品提交、难度星级
- **提醒**：写入手机日历，由系统日历到点提醒；不需要后端、不需要联网
- **自动绑定（可选）**：配置云环境后，进入小程序自动获取 openid

## 运行

1. 微信开发者工具 → 导入项目 → 选择本目录
2. `project.config.json` 的 AppID 当前为 `touristappid`，请替换成自己的小程序 AppID
3. 编译后用真机预览测试

## 数据同步

`utils/catalog.js` 是从仓库根目录 `index.html` 导出的数据快照。更新后重新生成：

```bash
node tools/export-catalog.js
```

## 常见问题：`addPhoneCalendar:fail auth deny`

这是日历权限被拒绝，不是代码问题：

1. 公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引，勾选「日历（写入）」
2. iPhone：设置 → 微信 → 日历 → 允许；安卓：设置 → 应用 → 微信 → 权限 → 日历
3. 小程序右上角 `···` → 设置 → 授权管理 → 添加到日历 → 打开
4. 代码已内置权限引导，写入前也会先保存提醒

微信开发者工具的模拟器可能不支持写入日历，请用真机预览测试。
